# Web Tetris (웹 테트리스) 🎮

웹 브라우저에서 바로 즐길 수 있는 모던 테트리스 게임입니다.

## ✨ 주요 기능
- **공식 7가지 테트로미노**: I, O, T, S, Z, J, L 블록 구현
- **슈퍼 로테이션 시스템 (SRS)**: 벽 차기(Wall Kick) 지원
- **고스트 피스 (Ghost Piece)**: 블록이 떨어질 위치를 반투명으로 가이드
- **홀드 (Hold)**: 현재 블록을 보관하고 필요할 때 교체
- **다음 블록 미리보기**: 다음 나올 5개의 블록을 우측 패널에 표시
- **반응형 & 모바일 지원**: 터치 컨트롤 지원

## 🕹 조작법
| 키 | 기능 |
|---|---|
| `←` `→` | 블록 좌우 이동 |
| `↑` | 시계 방향 회전 |
| `Z` | 반시계 방향 회전 |
| `↓` | 소프트 드롭 (천천히 빠르게 내리기) |
| `Space` | 하드 드롭 (즉시 바닥에 떨어뜨리기) |
| `C` | 홀드 (블록 보관) |
| `P` / `ESC` | 일시정지 |

## 🚀 실행 방법
`index.html` 파일을 브라우저로 열거나 더블클릭하여 바로 플레이할 수 있습니다.
